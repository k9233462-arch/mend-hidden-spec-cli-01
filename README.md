mend is one command-line patch tool that reads every edit format AI models write — unified diffs (even with wrong line numbers), SEARCH/REPLACE blocks, V4A patches and text-editor tool calls as JSON — finds the lines each edit names even when the model drifted their whitespace or indentation, and changes every file or none, exactly as SPEC.md in this repository specifies.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```
